Mailroute

A mail stream guard that treats inbox delivery as an auditable rules engine, not a black box: quarantine, review, and signed events live in the same path.

mail securityquarantineaudit trail

Core offer

  • Rule-driven IMAP and SMTP inspection with operator-friendly quarantine.
  • Audited propose/apply/revert cycles for rule changes.
  • Signed event output for downstream automation or escalation.

Operational fit

  • Small teams that need more control than hosted mail filters expose.
  • Mail lanes where false positives and operator review both matter.
  • Environments that want message policy coupled to local tooling.

Current focus

  • Inspection rule ergonomics and review workflow.
  • Glither-backed validation around message handling.
  • Safe integration with the evolving mail stack and governance surfaces.

The value is not just filtering more mail. It is making every filtering decision, change, and handoff inspectable after the fact.
