Matches

A browser-native studio for deterministic cinematic combat, tactical choreography, and exportable timelines that stay reproducible across runs.

3d viewportdsl editorrender pipeline

Core offer

  • Intent-driven combat composition with grounded locomotion.
  • Timeline, contact, and camera export from the same simulation run.
  • Offline and headless execution paths for rendering and testing.

Who it fits

  • Animation-heavy prototyping where repeatability matters.
  • Browser tools for choreography, machinima, or simulation reviews.
  • Pipelines that need semantic event output as well as visuals.

Current focus

  • Per-bone timelines and export stability.
  • Tactical AI behaviors that still stay inspectable.
  • Tooling that bridges browser authoring and offline render jobs.

Matches is built like a production tool rather than a toy demo: dense interfaces, inspectable state, and outputs that can feed downstream work.
