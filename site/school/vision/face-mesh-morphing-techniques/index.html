Face Mesh Morphing Techniques

Convincing face morphing is geometry first: stable landmarks, shared triangle topology, two texture maps, and one interpolation parameter moving shape and color together.

open live viewerall school modules

1. Face points

A face point, or landmark, is a named coordinate on a stable location such as an eye corner, nostril edge, lip contour, chin, or cheek. Viewer data normalizes each point into image space.

x: 0.0 left  -> 1.0 right
y: 0.0 top   -> 1.0 bottom
z: relative depth

The renderer maps those points into centered Three.js coordinates and flips the image y-axis:

world_x = (x - 0.5) * 2
world_y = -(y - 0.5) * 2
world_z = z * depth_scale

2. From points to triangles

Points alone are not a surface. A triangle mesh lets the GPU interpolate position, texture coordinates, and normals. Every expression must use the same triangle list, so a point keeps the same neighbors while the mouth, brow, or cheek moves.

ValuePurpose
positionPlaces the surface in space.
UVSelects the matching texture location.
normalSupports lighting and surface inspection.

3. Voronoi and Delaunay intuition

Voronoi cells describe the image region closest to each landmark. Delaunay triangles connect nearby landmarks into a surface the GPU can draw. The triangle mesh is the rendered structure; Voronoi regions help explain which landmark owns a local deformation.

detect landmarks -> build Delaunay triangles -> audit regions with Voronoi intuition

A triangle crossing a semantic boundary, such as lip to cheek or eyelid to forehead, produces visible shearing.

4. Morphing positions

The basic morph is linear interpolation:

P(t) = A + (B - A) * t
SymbolMeaning
ALandmark position in the source expression.
BMatching position in the destination expression.
tMorph amount from 0 to 1.

At t = 0.5, every point is halfway between its source and destination. Shared topology keeps every triangle coherent during the transition.

5. Texture coordinates and dual UVs

Moving geometry with fixed texture coordinates smears the face. The viewer therefore carries two UV sets, one for each expression texture.

UV setSamples
uvASource texture at source landmark coordinates.
uvBDestination texture at destination coordinates.
color = mix(textureA(uvA), textureB(uvB), t)

Geometry and color use the same morph amount, while each image is sampled through the landmarks that belong to it.

6. Transforms

TransformPurpose
normalize pointsPlaces every image tile in one coordinate frame.
flip yConverts image coordinates to view coordinates.
scale x and yCenters normalized image space in a 3D plane.
scale zKeeps depth visible without tearing the face.
camera orbitExposes the mesh from different angles.

Transforms determine whether landmarks line up, whether the face is centered, and whether depth reads as structure instead of noise.

7. Debugging checklist

  1. Confirm both expressions use the same landmark count.
  2. Verify point indices remain stable between A and B.
  3. Check that triangles do not cross semantic boundaries.
  4. Confirm the y-axis orientation.
  5. Bind each UV set to the correct expression texture.
  6. Keep z-depth strong enough to show form but weak enough to avoid tearing.
  7. Inspect wireframe coherence at t = 0, 0.5, and 1.

The live viewer exposes A/B selection, the morph slider, random traversal, wireframe, sharpness, orbit, immersive mode, and fullscreen as inspection controls.

8. Privacy boundary

Face landmarks can become biometric data when tied to a real person or identity workflow. These images and meshes are learning assets. A production system needs consent, provenance, retention limits, and a precise statement of whether it performs recognition, verification, or visual transformation only.
